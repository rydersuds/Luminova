# Massage Fenix — site redesign

A static redesign of the [massagecalgary.ca](https://massagecalgary.ca/index.html) homepage. There's no build step: open `index.html` in a browser.

- `index.html`: page markup, SEO meta and LocalBusiness structured data
- `styles.css`: design tokens, layout and responsive rules
- `script.js`: mobile menu, service filters, today's hours (Calgary time), scroll reveal

Booking and price-list buttons link to the existing pages on massagecalgary.ca.
